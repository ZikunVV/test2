# Портал Управляющей Компании ЖКХ (WORKFLOW)

Система управления заявками, жилым фондом, сотрудниками и картой объектов для управляющих организаций и ЖЭК.

## 🚀 Как загрузить проект на GitHub (без ошибки «Yowza, that's a lot of files»):
Веб-интерфейс GitHub ограничивает загрузку через браузер до 100 файлов.
Чтобы загрузить проект полностью:
1. Запустите файл `push_to_github.bat` (для Windows) или `./push_to_github.sh` (для Linux/macOS).
2. Либо воспользуйтесь программой **[GitHub Desktop](https://desktop.github.com/)** (`File` -> `Add Local Repository` -> `Publish`).
3. Подробная инструкция со всеми шагами находится в файле **[GITHUB_UPLOAD_GUIDE.md](./GITHUB_UPLOAD_GUIDE.md)**.

## Локальный запуск:
```bash
npm install
npm run dev
```
Откройте в браузере: http://localhost:3000

## Сборка:
```bash
npm run build
```
