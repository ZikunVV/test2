# Руководство: Как загрузить проект на GitHub без ошибки «Yowza, that’s a lot of files»

## Почему GitHub пишет «Yowza, that’s a lot of files»?
В веб-интерфейсе GitHub (когда вы нажимаете кнопку **«Add file» -> «Upload files»** в браузере) стоит жёсткое ограничение: **не более 100 файлов за один раз**.
Так как этот проект является полноценным современным веб-приложением с десятками компонентов, стилей и иконок, перетаскивание папки целиком через окно браузера блокируется сайтом GitHub.

---

## 🚀 3 простых способа загрузить проект на GitHub

### 🌟 Вариант 1 (Самый простой без терминала): Через GitHub Desktop
Если вы не хотите пользоваться командной строкой:
1. Скачайте бесплатную официальную программу **[GitHub Desktop](https://desktop.github.com/)** и войдите в свой GitHub аккаунт.
2. В программе нажмите меню **File** → **Add Local Repository...** (или нажмите `Ctrl + O`).
3. Укажите папку с распакованным проектом.
   *(Если появится надпись «This directory does not appear to be a Git repository», нажмите синюю ссылку **«create a repository»**)*.
4. В левом нижнем углу в поле Summary введите любое название (например: `First commit`) и нажмите **Commit to main**.
5. Нажмите кнопку **Publish repository** в верхней панели.
6. Выберите название репозитория на GitHub (публичный или приватный) и нажмите **Publish Repository**.
   **Готово! Проект со всеми файлами появится на вашем GitHub.**

---

### ⚡ Вариант 2 (В один клик через готовый скрипт)
1. Создайте пустой репозиторий на сайте [github.com/new](https://github.com/new) (например `gkh-portal`). **Не ставьте галочку «Add a README file»!**
2. Скопируйте ссылку на созданный репозиторий (вида `https://github.com/ВАШ_ЛОГИН/gkh-portal.git`).
3. Распакуйте скачанный ZIP архив проекта в отдельную папку.
4. Запустите файл:
   - Для **Windows**: дважды кликните по файлу `push_to_github.bat`
   - Для **Mac / Linux**: откройте терминал в этой папке и запустите `./push_to_github.sh`
5. Вставьте скопированную ссылку на репозиторий и нажмите **Enter**.
   Скрипт сам всё загрузит на GitHub!

---

### 💻 Вариант 3: Через терминал (стандартный способ Git)
Если у вас установлен Git (или Git Bash):
1. Откройте терминал (командную строку) в папке с распакованным проектом.
2. Выполните по очереди команды:
\`\`\`bash
git init
git add .
git commit -m "Первая загрузка проекта"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
\`\`\`

*(Замените `https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git` на ссылку вашего репозитория)*.

---

### ⚠️ Важно: Папка `node_modules`
Никогда не загружайте на GitHub папку `node_modules` (в ней тысячи системных файлов). В скачанном архиве проекта этой папки нет, а в файле `.gitignore` она уже исключена.
При развертывании на Vercel или другом хостинге зависимости установятся автоматически командой `npm install`.
